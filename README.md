# Excel → PDF 일괄 변환기

엑셀 파일(.xlsx, .xls, .xlsm, .xlsb)을 PDF로 일괄 변환하는 Windows 전용 데스크톱 프로그램입니다.

---

## 요구사항

| 항목 | 버전 |
|---|---|
| Windows | 10 / 11 |
| Microsoft Excel | 2016 이상 (설치 필수) |
| Python | 3.10 이상 |

---

## 설치

```bash
pip install -r requirements.txt
```

**설치되는 패키지**

| 패키지 | 용도 |
|---|---|
| `pywin32` | Excel COM 자동화 |
| `tkinterdnd2` | 드래그 앤 드롭 지원 |
| `pyinstaller` | .exe 패키징 |

---

## 실행

```bash
python main.py
```

시작 시 Microsoft Excel 설치 여부를 자동으로 확인합니다.  
Excel이 설치되어 있지 않으면 오류 메시지와 함께 종료됩니다.

---

## 사용법

### 1. 파일 추가

변환할 엑셀 파일을 추가하는 방법은 세 가지입니다.

**방법 A — 폴더 선택**
1. `폴더 선택…` 버튼 클릭
2. 엑셀 파일이 있는 폴더 선택
3. `하위 폴더 포함` 체크박스로 재귀 탐색 여부 선택

**방법 B — 파일 직접 추가**
1. `+ 파일 추가` 버튼 클릭
2. 변환할 엑셀 파일을 다중 선택 (Ctrl 또는 Shift 클릭)

**방법 C — 드래그 앤 드롭** *(tkinterdnd2 설치 시)*
- 탐색기에서 파일 또는 폴더를 목록 영역으로 드래그

> 열려 있는 엑셀 파일(`~$` 로 시작하는 임시 파일)은 자동으로 제외됩니다.

---

### 2. 변환 옵션 설정

오른쪽 옵션 패널에서 설정합니다.

#### 시트 범위

| 옵션 | 설명 |
|---|---|
| 모든 시트 변환 | 숨겨진 시트를 제외한 모든 워크시트를 하나의 PDF로 |
| 활성 시트만 변환 | 파일을 열었을 때 맨 앞에 보이는 시트만 변환 |

#### 인쇄 옵션

| 옵션 | 설명 |
|---|---|
| 열 너비를 한 페이지에 맞추기 (FitToPage) | 가로로 잘리지 않도록 자동 축소 |
| 숨겨진 시트 건너뛰기 | 숨김 처리된 시트는 PDF에 포함하지 않음 |

#### PDF 저장 위치

| 옵션 | 설명 |
|---|---|
| 원본 파일과 같은 폴더 | `보고서.xlsx` → 같은 폴더에 `보고서.pdf` 생성 |
| 직접 지정 | `…` 버튼으로 저장 폴더 선택 |

#### 기존 PDF 처리

같은 이름의 PDF 파일이 이미 존재할 때의 동작을 선택합니다.

| 옵션 | 설명 |
|---|---|
| 덮어쓰기 | 기존 PDF를 새 파일로 교체 |
| 건너뛰기 | 변환하지 않고 다음 파일로 넘어감 |
| 이름 뒤에 번호 붙이기 | `보고서_1.pdf`, `보고서_2.pdf` 형식으로 저장 |

---

### 3. 변환 실행

1. `▶ 변환 시작` 버튼 클릭
2. 하단 진행률 바와 로그 창에서 진행 상황 확인
3. 변환 완료 후 팝업 메시지로 결과 요약 확인

변환 중 `■ 중지` 버튼을 클릭하면 현재 파일 완료 후 중단됩니다.

---

### 4. 완료 후

- `📂 출력 폴더 열기` — 변환된 PDF가 저장된 폴더를 탐색기로 바로 열기
- `로그 저장…` — 변환 결과 로그를 `.txt` 파일로 저장
- `로그 지우기` — 로그 창 초기화

---

## 로그 색상 안내

| 색상 | 의미 |
|---|---|
| 🟢 초록 | 변환 성공 |
| 🟡 노랑 | 건너뜀 (기존 PDF 존재) |
| 🔴 빨강 | 변환 실패 (오류 메시지 포함) |
| 🔵 파랑 | 정보 메시지 |
| 🟠 주황 | 경고 (사용자 중지 등) |

## exe 파일로 빌드

Python이 없는 PC에 배포할 때 사용합니다.

```bat
build.bat
```

빌드가 완료되면 `dist\excel2pdf\excel2pdf.exe` 가 생성됩니다.  
`dist\excel2pdf\` 폴더 전체를 복사하여 배포하세요.

> Excel은 실행 PC에도 반드시 설치되어 있어야 합니다.

## 자주 묻는 질문

**Q. 변환 중 Excel 창이 열리나요?**  
A. 아니요. Excel은 백그라운드에서 숨김 모드로 실행되므로 화면에 표시되지 않습니다.

**Q. 변환 실패 원인은 어떻게 확인하나요?**  
A. 로그 창의 빨간 줄에 오류 내용이 표시됩니다. `로그 저장…` 버튼으로 파일로 남길 수 있습니다.

**Q. 암호가 걸린 파일은 어떻게 되나요?**  
A. 변환 실패로 처리되고 로그에 기록됩니다. 해당 파일은 건너뛰고 다음 파일을 계속 변환합니다.

**Q. 변환 후 EXCEL.EXE 프로세스가 남아 있나요?**  
A. 남지 않습니다. 변환 완료 또는 오류 발생 시 COM 레퍼런스를 완전히 해제하고 프로세스를 종료합니다.

**Q. 빈 시트가 있으면 오류가 나나요?**  
A. 빈 시트는 자동으로 건너뜁니다. 모든 시트가 비어 있으면 해당 파일이 실패로 기록됩니다.
